# Manual de usuario de la demo

## Antes de ingresar

La aplicación es una demostración administrativa con **DATOS SINTÉTICOS**. No introduzca nombres, DNI, teléfonos, correos reales, diagnósticos, historias clínicas ni archivos de una organización real.

## Recorrido sugerido

1. Inicie sesión con una cuenta creada por el operador de la demo.
2. Revise **Organización** y **Procesos** para conocer la estructura sintética.
3. Consulte **Indicadores**, **Auditorías**, **Mejora**, **Riesgos**, **Reportes** y **Analítica**.
4. Descargue solo plantillas o exportaciones sintéticas; no las sustituya por información real.
5. Cierre sesión al terminar, especialmente en un equipo compartido.

## Roles y límites

Cada pantalla se habilita por capacidad. Un autor no puede aprobar su propia versión ni aceptar controles que requieren segregación. Los mensajes de acceso denegado no deben evadirse. La demo no brinda atención, diagnóstico, recomendaciones terapéuticas ni decisiones sobre personas.

## Soporte demostrativo

El operador puede reiniciar el conjunto sintético o retirar temporalmente la demo. No existe compromiso de disponibilidad, conservación de una sesión, servicio clínico ni soporte de producción.
