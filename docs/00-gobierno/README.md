# P00 — Definición y gobierno

**Estado:** aprobada internamente  
**Puerta:** G00 cerrada, 10/10 controles conformes  
**Versión del expediente fuente:** 1.0

## Decisión

Trazamétrica Salud Perú se define como una investigación aplicada y un portafolio profesional de gestión administrativa en salud. El proyecto demostrará trazabilidad de procesos, indicadores, calidad y mejora continua mediante datos exclusivamente sintéticos.

## Límites aprobados

- No es un sistema clínico ni toma decisiones médicas.
- No procesa datos personales o de salud reales.
- No representa ni afirma aprobación de clínicas o autoridades.
- No emite certificaciones ni acredita cumplimiento de una norma.
- El MVP debe poder ejecutarse con herramientas gratuitas o de uso local.
- Los cambios de alcance requieren registro de fuente, impacto, responsable, prueba y reversión.

## Gobierno

El titular del repositorio actúa como responsable del producto y aprobador de puertas. Cada parte debe identificar objetivo, entradas, salidas, dependencias, riesgos, criterios de aceptación y evidencia.
