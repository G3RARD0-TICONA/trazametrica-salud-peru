# P01 — Demanda laboral y perfiles objetivo

**Estado:** aprobada internamente  
**Puerta:** G01 cerrada, 10/10 controles conformes  
**Muestra:** 10 publicaciones públicas de SANNA, AUNA y Grupo San Pablo

## Conclusión aprobada

La muestra exploratoria evidencia demanda recurrente de Excel, KPI, procesos, calidad de datos y visualización. Power BI y SQL adquieren mayor peso en posiciones analíticas. Python y estadística avanzada se mantienen como diferenciadores posteriores, no como sustitutos del gobierno de datos ni de la experiencia sectorial.

## Perfiles objetivo

- **Acceso directo:** asistencia o nivel junior en procesos, calidad, planeamiento e indicadores.
- **Desarrollo profesional:** análisis de indicadores, planeamiento y BI.
- **Referencia funcional:** jefaturas clínicas o de calidad utilizadas para extraer requisitos, no como puestos de acceso inmediato.

## Prioridad trasladada al producto

| Prioridad | Capacidades |
|---|---|
| Núcleo del MVP | Excel, KPI, procesos, calidad de datos y documentación |
| Arquitectura del MVP | PostgreSQL, SQL, trazabilidad y gobierno de datos |
| Salida analítica | Exportaciones limpias y Power BI Desktop local |
| Gestión de calidad | Auditorías, hallazgos, no conformidades y acciones correctivas |
| Versión posterior | Python analítico, series de tiempo, regresión y pronósticos |

## Limitación metodológica

Las diez publicaciones constituyen una muestra documental no probabilística; no representan todo el mercado laboral peruano. La línea base deberá actualizarse con fecha, estado, fuente y criterios de inclusión reproducibles.
